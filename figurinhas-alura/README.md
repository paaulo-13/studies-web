🌿 Álbum Botânico

Projeto desenvolvido durante a Imersão Arquitetura Web com IA da Alura.

Ao invés de manter o tema original proposto durante a imersão, adaptei toda a aplicação para um álbum de botânica, personalizando identidade visual, textos e conteúdo para criar um projeto mais alinhado aos meus interesses e ao meu portfólio.
